## Long description

**You know that friend who thinks they know everything? Make them prove it.**

Who's Bluffing is a free trivia game for your Discord server. Ten questions. Pick an answer, then say how sure you are. Being confidently wrong is what gets you. Every answer comes with its sources.

**Play with friends**
Type `/bluff party`, pick a topic and difficulty, and hit **Start party**. Friends tap **Join** and get the same ten questions. Answers stay private; joining shares your display name and final score with the group. See who actually knew their stuff, then hit **Rematch** for ten new questions.

Memes, history, languages, AI and more. Pick whatever your group argues about.

**Just want a quick game?**
Type `/bluff play` for a private round. Play again, or hit **Challenge** and let a friend try the same ten questions. Sharing is up to you. No setup needed to play.

**Optional daily question**
An admin can use `/bluff setup` to put a daily question in a channel. Everyone answers, then the reveal shows the answer, sources, and how the server did. Roast mode is off by default.

**Commands**
- `/bluff party` — play the same ten questions with friends
- `/bluff play` — play a private round
- `/bluff help` — how it works
- `/bluff setup` — set up an optional daily question (Manage Server required)
- `/bluff question` — post today's question
- `/bluff reveal` — reveal today's answer early (Manage Server required)
- `/bluff stats` — see the server leaderboard
- `/bluff invite` — add it to another server

Free. No ads. You can also [try it in your browser](https://whosbluffing.com/) without making an account.
