Who's Bluffing? for Slack

A little trivia for the coworker who always has an answer. Start /bluff party, pick a topic and difficulty, and let everyone join. Same ten questions, private answers. Compare scores, find out who was bluffing, then run it back with fresh questions.

Add to Slack See the commands

Free. One install per workspace. Joining a group round shares your display name and final score in that channel.

Commands

Slash commands

Type them in any channel. The same list, with Discord’s and the web game’s, is on the commands page.

/bluff

Opens a private menu with Play solo and Play with friends. Nothing is posted to the channel until you start a party.

Options
None
Who can run it
Any member

/bluff party

Choose a topic and difficulty, then start a shared round in this channel. Friends tap Join to answer the same ten questions privately. Joining shares your Slack display name and final score in the channel. Results refreshes the scores; a finished player can start a fresh shared rematch. Parties expire after one hour.

Options
None
Who can run it
Any member

/bluff play

Opens a private topic and difficulty picker. Play ten questions, choose your confidence after each answer, and see the source and your points. Finish to see your score and type, share a friend challenge, or play fresh questions with the same settings.

Options
None
Who can run it
Any member

/bluff question

Posts today’s question in this channel. In the chosen channel (or when none is chosen yet) it becomes the day’s post; elsewhere it posts a copy whose answers count the same. After today’s reveal it posts nothing and says so.

Options
None
Who can run it
Any member

/bluff setup #channel [hour] [roast on|off] [reveal N]

Posts the question in #channel every day at that hour in your time zone, and reveals the answer N hours later. Type # and pick the channel so Slack links it. Everyone sees the times in their own time zone.

Options
  • #channel where the daily question goes; for a private channel, run /invite @whosbluffing in it first
  • hour 0 to 23 in your Slack time zone; add utc after it for UTC (left out: 14:00 UTC)
  • roast on|off on names the biggest bluffer at the reveal and shows negative points (off by default)
  • reveal N hours from the post to the reveal, 2 to 23 (default 8)
Who can run it
Any member

/bluff setup roast on|off

Changes roast mode only; the channel and the hour stay as they are. /bluff setup reveal N changes only the hours to the reveal.

Options
None
Who can run it
Any member

/bluff reveal

Reveals the open question now, for everyone.

Options
None
Who can run it
Any member

/bluff stats

Posts this workspace’s leaderboard for the last 30 days in the channel: the top 10 by total points (ties: more answers first) and how many members answered. Only revealed days count.

Options
None
Who can run it
Any member

Privacy

What we store

  • Per workspaceThe workspace id, the bot token, the chosen channel, the posting hour, roast mode, and each day’s post with its question.
  • Per memberYour choices, confidence, progress and points, keyed by a salted hash of your member id. Group rounds temporarily keep the display name you agree to share when joining.
  • NeverMessage text, raw member ids or emails. Daily leaderboard names are looked up while it is drawn; group display names expire with the temporary session.

Group answers stay private. Joining shares your display name and final score in the channel; temporary party records expire after one hour and are removed in the next cleanup. The game server receives only hashed member and workspace ids. Full details: privacy policy.

Troubleshooting

Commands not working?

Slack says /bluff is not a valid command

Who's Bluffing isn’t installed in this workspace, or was removed. Install it again from the Add to Slack link.

“I can’t post in that channel”

The channel is private. Run /invite @whosbluffing in it, then /bluff setup #channel again. Public channels work without an invite.

The question didn’t post today

The hour you type is read in your Slack time zone (or in UTC with utc after it) and kept in UTC; the setup reply shows both. Who's Bluffing checks at the top of every hour and posts once a day, as soon as your hour has come; if you set it up after that hour, today’s question posts at the next full hour. Run /bluff setup #channel HH to check the channel and hour.

The confidence buttons stopped working

For a daily question, tap A or B again to open a fresh confidence picker. For a party, tap Join / Resume. Private game sessions and parties expire after one hour; start a new round after that.

“Who's Bluffing is taking a break”

The game server didn’t answer. Try again in a minute; the status page shows whether it is up.

FAQ

Questions

What does it cost?

Nothing. Who's Bluffing is free and non-commercial, with no ads and no paid plan.

Who can change the channel or the hour?

Any member can run /bluff setup. The latest setup wins.

What is roast mode?

Off by default: the reveal says “Someone was 90% sure…”, and the points list shows only members above 0. /bluff setup roast on names the biggest bluffer and shows everyone’s points.

Does it work with Enterprise Grid?

It installs per workspace. Org-wide Enterprise Grid installs are not supported.

Is it in the Slack App Directory?

Not yet. Installs go through the Add to Slack link on this page.
