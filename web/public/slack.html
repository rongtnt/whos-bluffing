Who's Bluffing? for Slack

Install once and your team gets the daily game in a channel. Members play in a form, and the post keeps today’s leaderboard.

Add to Slack See the commands

Free. One install per workspace. No message text, names or emails are stored.

Commands

Slash commands

Type them in any channel. A member who already played today gets their result again, not a second game.

Who's Bluffing slash commands
/bluffPosts today’s game in this channel.
/bluff setup #channel [HH]Posts the game in #channel every day at hour HH, in UTC (0–23, default 14).
/bluff statsPosts this workspace’s leaderboard for the last 30 days: the top 10 by total hits (ties go to whoever played more) and how many members played.

Privacy

What we store

  • Per workspaceThe workspace id, the chosen channel, the bot token and the posting hour.
  • Per memberPer-day scores, keyed by a salted hash of the member id. Never raw Slack ids.
  • NeverMessage text, names or emails. Display names are fetched only while a leaderboard is drawn.

The game server receives only hashed member and workspace ids. Full details: privacy policy.

Troubleshooting

Something not working?

“I can’t post in that channel”

The channel is private. Run /invite @whosbluffing in it, then /bluff setup #channel again. Public channels work without an invite.

The game didn’t post today

The hour is in UTC. Who's Bluffing checks at the top of every hour and posts once a day, as soon as your hour has come; if you set it up after that hour, today’s game posts at the next full hour. Run /bluff setup #channel HH to check the channel and hour.

My result disappeared, or “Who's Bluffing is taking a break”

The private result uses a Slack link that lasts 30 minutes after you press Play; press Play again to see it. “Taking a break” means the game server didn’t answer: try again in a minute.

FAQ

Questions

What does it cost?

Nothing. Who's Bluffing is free and non-commercial, with no ads and no paid plan.

Who can change the channel or the hour?

Any member can run /bluff setup. The latest setup wins.

Does it work with Enterprise Grid?

It installs per workspace. Org-wide Enterprise Grid installs are not supported.

Is it in the Slack App Directory?

Not yet. Installs go through the Add to Slack link on this page.
