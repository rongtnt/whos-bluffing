Classroom mode

Overconfidence, live in class

If you run the “give me a 90% range” demonstration, this does it with no clickers and no accounts. Students take a 5-minute test on their phones; the class’s calibration curve builds on your screen as they finish.

Create a class code Try the test yourself

Free. Works on any phone with a browser. Intro psychology, statistics, economics, decision making.

How it works

Three steps, five minutes

  1. Create a class code

    Open whosbluffing.com/class, give the class a name if you like, and keep the private dashboard link.

  2. Students join

    They open whosbluffing.com/test on their phones and enter the code. Twelve two-choice questions with a confidence rating, six 90% ranges.

  3. Project the dashboard

    The class chart appears once 5 students have finished and updates as more finish. Then discuss where the dots sit against the dashed line.

Privacy

Built for a classroom

  • Totals onlyYou see class aggregates and a CSV of totals, never anyone’s answers.
  • Nothing under 5 studentsThe dashboard shows only a count until 5 students have finished.
  • No accountsStudents are anonymous. Their answers join the research data without the class code.

Anyone with the dashboard link can see the class totals, so keep it to yourself; there is no way to recover it later.
