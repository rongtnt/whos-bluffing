Commands

Everything you can type in Discord and Slack, and the shortcuts of the web game, with who can run what.

Discord

Type /bluff in any server channel and pick a subcommand. Replies marked “only you” are private.

/bluff question

Posts today’s question in this channel now. If today’s question is already up, it links to it instead.

Options
None
Who can run it
Anyone

/bluff play

A private 10-question round (only you): pick A or B, say how sure you are, see the answer and your points, then Next. It ends with your score, your type and a Challenge button that posts your challenge link in the channel.

Options
None
Who can run it
Anyone

/bluff stats

Posts this server’s leaderboard for the last 30 days in the channel: the top 10 by points and how many members answered.

Options
None
Who can run it
Anyone

/bluff setup

Sets where and when the daily question goes, how many hours later the answer is revealed, and roast mode. Every option is optional: a missing one keeps its value. A new channel gets a short hello, which also checks that Who's Bluffing may post there.

Options
  • channel where the daily question goes (a text or announcement channel)
  • hour the posting hour in UTC, 0 to 23 (default 14); members see the post and reveal times in their own time zone
  • reveal hours from the post to the reveal, 2 to 23 (new servers start at 20)
  • roast on or off (default off): on names the biggest bluffer in the reveal
Who can run it
Manage Server

/bluff reveal

Reveals today’s answer now instead of waiting for the scheduled reveal.

Options
None
Who can run it
Manage Server

/bluff help

How Who's Bluffing works and the command list (only you).

Options
None
Who can run it
Anyone

/bluff invite

A link to add Who's Bluffing to another server (only you).

Options
None
Who can run it
Anyone

Commands not working?

/bluff doesn’t appear when I type /

Who's Bluffing was added without its commands. Add it again with the Add to Discord link, which asks for both the bot and the applications.commands scope, then reload Discord (Ctrl+R or Cmd+R).

“Only members with the Manage Server permission can do that”

/bluff setup and /bluff reveal need the Manage Server or Administrator permission. Ask someone who has it, or have an admin give your role Manage Server.

The leaderboard says “a member” instead of names

Names need the app’s Server Members Intent. If everyone shows as “a member”, the intent is off on our side: please tell us on GitHub. Only the first 1,000 members of a server can be named; others always show as “a member”.

“This interaction failed”

Update your Discord app (or reload the browser tab) and try again: older versions can’t show the buttons. If it keeps happening, the game server may be down for a moment; the status page shows whether it answers.

“I can’t post in that channel”

Give Who's Bluffing the View Channel and Send Messages permissions in that channel, or pick another one with /bluff setup channel:.

The app shows as offline

That is normal. Who's Bluffing answers through Discord’s interactions endpoint and never connects to the live gateway, so it always looks offline while it works.

Slack

Type them in any channel. Anything else after /bluff shows the command list, only to you.

/bluff

Posts today’s question in this channel. In the chosen channel (or when none is chosen yet) it becomes the day’s post; elsewhere it posts a copy whose answers count the same. After today’s reveal it posts nothing and says so.

Options
None
Who can run it
Any member

/bluff setup #channel [hour] [roast on|off] [reveal N]

Posts the question in #channel every day at that hour in your time zone, and reveals the answer N hours later. Type # and pick the channel so Slack links it. Everyone sees the times in their own time zone.

Options
  • #channel where the daily question goes; for a private channel, run /invite @whosbluffing in it first
  • hour 0 to 23 in your Slack time zone; add utc after it for UTC (left out: 14:00 UTC)
  • roast on|off on names the biggest bluffer at the reveal and shows negative points (off by default)
  • reveal N hours from the post to the reveal, 2 to 23 (default 8)
Who can run it
Any member

/bluff setup roast on|off

Changes roast mode only; the channel and the hour stay as they are. /bluff setup reveal N changes only the hours to the reveal.

Options
None
Who can run it
Any member

/bluff reveal

Reveals the open question now, for everyone.

Options
None
Who can run it
Any member

/bluff stats

Posts this workspace’s leaderboard for the last 30 days in the channel: the top 10 by total points (ties: more answers first) and how many members answered. Only revealed days count.

Options
None
Who can run it
Any member

Commands not working?

Slack says /bluff is not a valid command

Who's Bluffing isn’t installed in this workspace, or was removed. Install it again from the Add to Slack link.

“I can’t post in that channel”

The channel is private. Run /invite @whosbluffing in it, then /bluff setup #channel again. Public channels work without an invite.

The question didn’t post today

The hour you type is read in your Slack time zone (or in UTC with utc after it) and kept in UTC; the setup reply shows both. Who's Bluffing checks at the top of every hour and posts once a day, as soon as your hour has come; if you set it up after that hour, today’s question posts at the next full hour. Run /bluff setup #channel HH to check the channel and hour.

The confidence buttons stopped working

The private picker uses a Slack link that lasts 30 minutes after you tap A or B. Tap A or B again.

“Who's Bluffing is taking a break”

The game server didn’t answer. Try again in a minute; the status page shows whether it is up.

Not working?

The game doesn’t load

It needs JavaScript. Reload the page; if an extension blocks scripts, allow this site.

The keys don’t do anything

Click the page first so it has the focus, and make sure the cursor isn’t in a text box. Keys work only while a question or its answer is on screen.

My streak or my round in progress disappeared

Both live in your browser’s storage. A private window or clearing the site’s data starts fresh.

“We couldn’t reach the server”

Your answer is still on screen: press Try again. If it keeps happening, the status page shows whether the game server answers.
