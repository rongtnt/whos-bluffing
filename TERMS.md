## Acceptable use

Please don't:

- send automated or bulk traffic, or try to overload, probe or break the site, the API or the Slack app;
- submit made-up answers or reports to distort the public numbers, the research data or the question pool;
- write personal information about anyone in the report box under a question;
- use Who's Bluffing to break the law or anyone else's rights.

We may block traffic that breaks these rules.

## The API

The daily API (documented at [/docs/api](/docs/api)) exists for the Who's Bluffing web game and Slack app. If you build on it, keep request volumes low, never send personal data, and expect it to change without notice.

## Your data
